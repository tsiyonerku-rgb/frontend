# Personal Webpage

A clean, semantic HTML personal profile page introducing my background, education, hobbies, and contact information.

## Overview

This project serves as a lightweight static portfolio page built using semantic HTML5 elements. It features easy in-page navigation linking directly to different sections about my life and interests.

## Features

- **Semantic HTML5 Structure:** Structured with `<header>`, `<nav>`, `<main>`, `<section>`, `<figure>`, and `<footer>`.
- **Smooth Page Navigation:** Internal anchor links for quick jumps across sections.
- **Personal Background:** Highlights academic journey, hobbies, and family values.
- **Direct Contact Links:** Click-to-email and click-to-call integration.

## Sections Included

- **Hobby:** Overview of personal interests, music, and daily activities.
- **Picture:** A featured photo section utilizing semantic figure tags.
- **School History:** Academic timeline from primary school to university.
- **Contact:** Direct communication channels via email and phone.

## Technologies Used

- **HTML5**
